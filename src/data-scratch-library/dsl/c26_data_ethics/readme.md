# Chapter 26 – Data Ethics

A survey of ethical considerations that arise in data science practice.

---

## Key Topics

| Topic | Summary |
|---|---|
| **Building bad data products** | Unintended offensive outputs (e.g. biased image classifiers, manipulable chat bots) |
| **Accuracy vs. fairness** | A model can be "accurate" yet systematically disadvantage a demographic group; multiple fairness definitions often conflict |
| **Collaboration** | Tensions when governments or organisations request data access for surveillance or censorship |
| **Interpretability** | Trade-off between model performance and the ability to explain predictions |
| **Recommendations** | Optimising engagement can amplify conspiracy theories and misinformation |
| **Biased data** | Training data reflects real-world biases; downstream models inherit and scale them |
| **Data protection** | Responsibilities around user data: advertising, research, law enforcement, terms of service |

---

## Key Takeaway

There is rarely a single "right" answer. The important practice is to **actively
consider** the ethical consequences of the data products you build, the data you
collect, and the decisions your models influence.
