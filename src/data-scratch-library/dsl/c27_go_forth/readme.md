# Chapter 27 – Go Forth and Do Data Science

A guide to next steps: essential libraries, tools, and project ideas for
continuing your data-science journey beyond "from scratch."

---

## Recommended Tools & Libraries

| Tool | Purpose |
|---|---|
| **IPython** | Enhanced interactive Python shell |
| **NumPy** | Fast n-dimensional arrays and linear algebra |
| **pandas** | DataFrames for data wrangling and analysis |
| **scikit-learn** | Production-grade machine learning |
| **matplotlib** | Static plotting and visualisation |
| **seaborn** | Statistical visualisations on top of matplotlib |
| **D3.js** | Interactive, web-based data visualisations (JavaScript) |
| **Bokeh** | D3-style interactivity from Python |
| **TensorFlow / PyTorch** | Deep-learning frameworks |

## Project Ideas

- **News classifier** — train a Naive Bayes model on Hacker News headlines.
- **Fire-truck network** — scrape 911 data and do social-network analysis.
- **Image classifier** — use logistic regression or PCA on pixel colours.
- **Real-time visualisation** — stream geotagged tweets onto a spinning globe.
