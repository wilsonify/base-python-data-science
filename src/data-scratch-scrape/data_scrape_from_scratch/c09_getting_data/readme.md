# Chapter 9 – Getting Data (Scrape)

Web-scraping and API examples for acquiring data from external sources.

| Script | Description |
|---|---|

| Technique | Library |
|---|---|

| HTML parsing | `beautifulsoup4` (`bs4`) |
| JSON handling | `json` (stdlib) |
| API authentication | OAuth / bearer tokens |
