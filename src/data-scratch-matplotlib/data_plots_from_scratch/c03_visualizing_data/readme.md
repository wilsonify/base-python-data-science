# Chapter 3 – Visualising Data

Matplotlib chart helpers for the plots used throughout *Data Science from Scratch*.

---

## Module Contents

### `charts.py` — Plotting Functions

| Function | Description |
|---|---|
| `plot_normal_pdfs` | Overlay normal PDF curves with different parameters |
| `plot_normal_cdfs` | Overlay normal CDF curves |
| `plot_estimated_derivative` | Visualise numerical derivative estimation |
| `make_chart_salaries_by_tenure` | Scatter plot of salary vs. tenure |
| `make_graph_dot_product_as_vector_projection` | Vector projection diagram |
| `classify_and_plot_grid` | kNN decision boundary on a grid |
| `plot_cities` | Scatter plot of city locations |
| `make_hist` | Binomial-distribution histogram |
| `show_weights` | Visualise neural-network neuron weights |
| `compare_two_distributions` | Side-by-side distribution comparison |
| `plot_histogram` | General-purpose histogram |
| `scatter` | Two-series scatter plot |
| `make_scatterplot_matrix` | Pairwise scatter-plot matrix |
| `make_chart_scatter_plot` | Decorated scatter plot |
| `recolor_image` | k-means colour quantisation of an image |
| `plot_squared_clustering_errors` | Elbow plot for choosing k |
| `patch` / helper | Draw hatched patches |
